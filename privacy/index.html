Privacy Policy

whoistheMETRO · Metro Dashboard · Last updated 13 August 2026

Summary

Metro Dashboard is a private, single-user tool built and operated by whoistheMETRO to publish his own creative work to his own social media accounts. It is not offered to the public, has no user accounts, and collects no personal information from anyone.

What the application does

Metro Dashboard runs locally on the operator's own computer. It takes a video file supplied by the operator, prepares platform-specific versions of it, and uploads them to social media accounts that the operator personally owns and has authorised.

Information handled

  • Access tokens issued by the platforms the operator connects (TikTok, Instagram, YouTube). These authorise posting to the operator's own accounts and are stored only in a local configuration file on the operator's computer.
  • Basic account details such as username and account ID, retrieved from the connected platform to confirm the correct account is connected and displayed in the local interface.
  • Video and caption content that the operator chooses to publish.

Information not collected

No data is collected from any third party. There are no other users. The application does not track visitors, does not use cookies or analytics, does not build profiles, and does not access the data of anyone other than the operator's own connected accounts.

Storage and retention

All credentials and media are stored locally on the operator's own machine. Nothing is stored on a public server. Video files are transferred to the operator's own cloud storage only as a temporary step where a platform's API requires a fetchable URL, and those temporary links expire automatically.

Sharing

No data is sold, rented, or shared with third parties. Data is transmitted only to the social media platform the operator has explicitly connected, for the sole purpose of publishing the operator's own content to the operator's own account.

Revoking access

Access can be revoked at any time from the connected platform's own settings — for example TikTok's Security & Permissions page, or Instagram's Apps and Websites page. Revoking access immediately stops all publishing.
